Manim Cheat Sheet & Quick Reference

Basic Scene Skeleton

from manim import *

class MyScene(Scene):
    def construct(self):
        circle = Circle(radius=1.0, color=BLUE)
        self.play(Create(circle))
        self.wait(1)

Common Mobjects (Objects)

Circle(radius=...), Square(side_length=...), Rectangle(width=..., height=...), Text("Hello", font_size=...), MathTex(r"e^{i\pi} + 1 = 0"), Axes(x_range=[...], y_range=[...]), Dot(), Line(start, end), Arrow(start, end)

Essential Animations

self.play(Create(mobj)), self.play(FadeIn(mobj)), self.play(FadeOut(mobj))
self.play(Transform(mobj1, mobj2)), self.play(ReplacementTransform(mobj1, mobj2))
self.play(Rotate(mobj, angle=PI/2)), self.play(mobj.animate.shift(UP * 2))

Hotkeys

Ctrl + Space: Monaco editor code autocompletion
